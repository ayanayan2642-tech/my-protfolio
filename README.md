# Muhammad Ayan — Portfolio V2

This is a completely redesigned portfolio with a high-contrast black/lime visual system, large kinetic typography, intro loader, animated orbital artwork, custom cursor, full-screen navigation, reveal-on-scroll transitions, and bespoke project visuals.

## Run it
1. Extract this ZIP.
2. Open the extracted `ayan-portfolio-v2` folder in VS Code.
3. Open `index.html` with Live Server or directly in your browser.

`style.css` is the compiled stylesheet used by the browser. `style.scss` is an editable SCSS source sample. To compile SCSS, install Dart Sass and run:

```bash
sass style.scss style.css
```

Important: `style.scss` is a modular SCSS source example for the design system, while `style.css` contains the complete website styling. Do not compile the shorter SCSS file over the complete CSS unless you merge the rules first.
